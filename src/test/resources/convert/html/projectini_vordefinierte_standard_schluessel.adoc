= Vordefinierte Standard-Schlüssel

Alle Schlüssel können, wahlweise in geschweiften oder eckigen Klammern, auch als Argument oder als Teil eines Argumentes über die Syntax 
*{dollarbracket}Schlüsselname}*
 oder 
*$[Schlüsselname]*
 verwendet werden, hier ein Beispiel:

 ide.Java.SourcePath = 
*{dollarbracket}project.root}*
/../../main/java
*/{dollarbracket}package}*

Folgende 
*Standard-Schlüssel*
 sind in LF-ET bereits vordefiniert:

[cols=2,options="header"]
|===

| Schlüssel
| Bedeutung

| dt
| Absoluter Pfad der Entscheidungstabelle

| dt.folder
| Absoluter Pfad des Ordners der Entscheidungstabelle

| dt.folder.name
| Name des Ordners der Entscheidungstabelle

| dt.name
| Name der Entscheidungstabelle

| dt.extension
| Extension der Entscheidungstabelle

| codetype
| Liefert Application, Scrapbook oder Interface Ermöglicht in Folgeverarbeitungen die Unterscheidung zwischen 'echtem' Code und Scrapbook- oder Interface-Code. So macht es z.B. keinen Sinn, nach der Generierung eines Scrapbooks oder Interfaces automatisch Testsuites zu starten

| project.drive
| Laufwerk des Speicherortes der LFET.Project.ini-Datei 1)

| project.root
| Absoluter Pfad des Speicherortes der LFET.Project.ini-Datei 1)

| src
| Absoluter Pfad des generierten Sourcecodes

| src.folder
| Ordner des generierten Sourcecodes

| src.name
| Name des generierten Sourcecodes

| src.extension
| Extension des generierten Sourcecodes

|===

Ebenfalls verwendet werden können

[cols=2]
|===

| -
| alle Schlüssel aus der Systemumgebung, wie z.B. user.name, user.dir oder user.home

| -
| alle Umgebungsvariablen

|===

Die verfügbaren Systemschlüssel und Umgebungsvariablen können in LF-ET unter dem Menüpunkt 
*Hilfe > Info > Details > System Properties*
 eingesehen werden.

[cols=2]
|===

| 1)
| Bei mehreren, verschachtelten LFET.Project.ini-Dateien wird hier die zuletzt gefundene (Haupt-) LFET.Project-ini-Datei verwendet.

|===
