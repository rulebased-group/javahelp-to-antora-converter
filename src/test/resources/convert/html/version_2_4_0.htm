Testfallgenerierung

 

Numerische Berechnungen

 

Die seitherige Bestimmung von zulässigen Bedingungswerten mit logischen Operationen wurde erweitert um numerische Berechnungs- und Vergleichsoperationen.

 

 

Die berechneten Werte können auch in Testanweisungen verwendet werden.

 

Weitere Informationen:

▪ Bestimmung von zulässigen Bedingungswerten

▪ Berechnete Werte in Testanweisungen verwenden.

 

 

Technik

 

Unterstützte Java-Runtime-Versionen

 

LF-ET ist nach wie vor eine reine Java-Anwendung und benötigt daher zur Ausführung nur eine Java-Laufzeitumgebung.

 

LF-ET 2.4.0 benötigt mindestens Java Version 8, ist getestet und freigegeben bis Java Version 21.

 

Auslieferung jetzt mit SBOM

 

Die Absicherung der Sicherheit von Netzwerken und Infrastruktur ist wichtig und zahlreiche Richtlinien sollen hierbei helfen, wie z.B. die Anforderungen des CRA (Cyber Resilience Act) oder NIS-2 (Network and Information Security).

 

LF-ET verwendet eine Reihe von Open-Source- Java-Bibliotheken (JAR-Files), die mit LF-ET schon immer offen und transparent ausgeliefert wurden:

▪

Reduziert auf das notwendige Minimum: Nur die tatsächlich zur Laufzeit benötigten Bibliotheken

▪

Die Bibliotheken werden nicht in LF-ET integriert, nicht verändert und bleiben offen sichtbar inkl. der jeweils genauen Versionsangaben

 

Neu: Um LF-ET noch besser gegen eventuelle Schwachstellen abzusichern, werden jetzt alle verwendeten Bibliotheken kontinuierlich automatisch geprüft:

▪

Sind Bibliotheken zwischenzeitlich von neu veröffentlichten Schwachstellen betroffen?

▪

Falls ja: Zwingend Ersatz durch eine neue Version oder durch eine alternative Bibliothek

 

Neu: Außerdem wird LF-ET jetzt immer mit einer neu generierten SBOM (Software Bill of Materials) in verschiedenen Formaten ausgeliefert:

▪

Derzeit werden die SBOM-Formate CyclonDX v1.5 JSON und CyclonDX v1.5 XML generiert
