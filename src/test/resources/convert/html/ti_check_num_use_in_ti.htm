Berechnete Werte in Testanweisungen verwenden

Mit folgendem Ausdruck können Werte aus der laufenden Berechung dynamisch in Testanweisungen eingebunden werden:

 

${ *LFET.num.Variablenname [ .fin | .bef | .aft ] [ : 000.000] }

 

${ *LFET.num.

Schlüssel-Präfix, leitet die Verwendung eines Berechnungsergebnisses in die Testanweisung ein, siehe auch: Testanweisungen mit Elementen aus der Entscheidungstabelle

Variablenname

Der Name einer Variablen

Falls die Variable nicht existiert wird der Hinweis "unbekannte Variable xxx" in die Testanweisung eingebunden

Optional

 

  .fin

final - das im Testfall finale Ergebnis für die Variable (Standard-Wert)

  .bef

before - der Variablenwert VOR der aktuellen Regel

  .aft

after - der Variablenwert NACH der aktuellen Regel

Optional

  : 000.000

 

Nach einem Doppelpunkt ein Zahlenformat, hauptsächlich zur Festlegung der gewünschten Vor- und Nachkommastellen

▪ keine Kommas, kein Tausender-Trennzeichen

▪ Dezimalzeichen ist der Punkt

}

Ende-Markierung des Ausdrucks

 

Beispiele:

 

Eine Variable 'score' wird in der Regel, in der die Testanweisung ausgeführt wird, noch verändert und hat dabei die folgenden Werte:

▪ 5.21892 - vor der Regel

▪ 7.38461 - nach der Regel und auch final für den Testfall

 

Testanweisung

Ergebnis

score: ${ *LFET.num.score }

score: 7.38461

score: ${ *LFET.num.score : 0000.000 }

score: 0007.385

score: ${ *LFET.num.score.bef }

score: 5.21892

score: ${ *LFET.num.score.bef : 0.00 }

score: 5.22
